# itjun-loves · 我们的爱

结婚纪念日表白网站：彩色情话气泡从散开慢慢汇聚成爱心，再炸开铺满屏幕。支持手机与电脑响应式。

- 结婚日期：2020-01-13
- 线上地址：https://itjun.github.io/itjun-loves/

## 本地开发

```bash
npm install
npm run dev
```

## 自定义

编辑 [src/config.js](src/config.js)：

- `WEDDING_DATE`：结婚日期
- `LOVE_WORDS`：顶部情话
- `BUBBLE_PHRASES`：气泡里的短句
- `BUBBLE_COLORS`：气泡配色

改完后 push 到 `main`，GitHub Actions 会自动部署。
